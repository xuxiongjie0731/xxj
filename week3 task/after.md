# Create a Private Repository with a README

Platform: GitHub.com, desktop browser, English interface.
Audience: A first-time GitHub user.
Task: Create your own private repository and confirm its README appears on the repository page.

## Before you start

- You have a GitHub account.
- You are signed in to github.com in a desktop browser. If you are not signed in, select **Sign in** in the top-right corner first.
- Your account can create repositories. Every personal account has this permission by default.

## Steps

1. In the top-right corner of any page, select the **+** menu, then select **New repository**.
2. Type a short, unique name, for example `docs-practice`, in the **Repository name** box. If the name is unavailable, select another name.
3. Under visibility, select **Private**. (You can change this later in **Settings**.)
4. Select the **Add a README file** checkbox.
5. Select **Create repository**.

## Result check

GitHub opens the new repository page at `github.com/<your-username>/<repo-name>`, and the README content is rendered below the file list. You can see your README text on the page.

If the page shows a "Quick setup" command box instead of the README content, the README option in step 4 was not selected. To recover:

1. Select **Settings**.
2. In the **Danger Zone**, select **Delete this repository** and confirm.
3. Repeat steps 1–5, and make sure you select **Add a README file** in step 4.

Check again: the repository page shows the README content.
