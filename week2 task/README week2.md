# Create a Private Repository with a README

**Platform:** GitHub.com, desktop browser, English interface
**Audience:** A first-time GitHub user
**Task:** Create your own private repository and confirm its README appears on the repository page.

## Prerequisites

- A GitHub account, and you are **signed in** at github.com in a desktop browser.
- Permission to create repositories in your own account (every personal account has this by default).

## Steps

1. In the top-right corner of any page, select the **+** menu, then select **New repository**.
2. In the **Repository name** box, type a short, unique name, for example `docs-practice`. If the name is unavailable, choose another name.
3. Under visibility, select the **Private** option.
4. Select the checkbox **Add a README file**.
5. Select **Create repository**.

## Result check

GitHub opens the new repository page at `github.com/<your-username>/<repo-name>`, and the README file is listed at the top of the file list with its content rendered below the file list.

If the page shows a "Quick setup" command box instead of a README, the README option in step 4 was not selected. Delete the empty repository (Settings → Danger Zone → Delete this repository) and repeat the steps, making sure step 4 is checked.
